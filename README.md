# Livro do Grupo

Projeto desenvolvido utilizando HTML, CSS e JavaScript.

O site apresenta os integrantes do grupo em formato de livro virtual, permitindo navegar entre as páginas para conhecer um pouco mais sobre cada participante.

## Tecnologias Utilizadas

* HTML
* CSS
* JavaScript
* Git
* GitHub
* GitHub Actions
* Vercel

## Funcionalidades

* Navegação entre páginas
* Interface em formato de livro
* Logs no console
* Pipeline CI/CD
* Hospedagem online
